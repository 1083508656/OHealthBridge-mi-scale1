# OHealth Device Bridge

让 OPPO 健康连接更多第三方体脂秤的 Xposed 模块。装上之后，你可以直接在 OPPO 健康里配对并使用支持的第三方秤：站上秤自动测量、自动记录；只有拿到有效阻抗的测量才会生成可靠的体脂、肌肉率、水分、骨量、内脏脂肪、基础代谢等身体成分数据。

## 功能

- 在 OPPO 健康的「添加设备 → 体脂秤」中显示并配对支持的设备。
- 站上秤即可开始测量，实时显示体重并自动保存；收到有效阻抗时才计算身体成分（体脂率、肌肉率、水分、骨量、内脏脂肪、基础代谢等）。
- 在任意页面站上秤也会自动称重并弹出测量页，无需手动进入测量页。
- 测量结果自动归入对应成员，无需手动认领。
- 读取支持 GATT 历史传输的秤内保存的测量记录。

## 支持的设备

| 设备 | 型号 | 支持状态 | 测试状态 |
| --- | --- | --- | --- |
| 小米体脂秤（一代） | XIAOMI-MI-SCALE-V1-BODY | 支持 | 已实测 |
| 小米体重秤（一代） | XIAOMI-MI-SCALE-V1 | 支持 | 未实测 |
| 小米体脂秤（二代） | XIAOMI-MI-SCALE-V2 | 支持 | 未实测 |
| 薄荷健康 B1 智能体脂秤（蚂蚁阿福联名款） | AFU-BH-TZ-B1 | 支持 | 已实测 |
| 京东健康 LEN-1001 体脂秤 | JD-LEN-1001 | 实验性支持：体重；阻抗取决于秤侧测量 | 未完成阻抗验证 |

目前仅适配上述型号。其中小米体脂秤（一代）与薄荷健康 B1 已经过真机实测；其余型号尚未逐台真机验证。LEN-1001 采用纯广播数据（无需蓝牙连接），广播帧包含阻抗字段，但实测既出现过有效值，也出现过 `0`；阻抗为 `0` 时模块只保存体重，不计算体脂等身体成分。

## 使用条件

- Android 8.0 或更高版本。
- 已安装并启用支持本模块的 LSPosed / Xposed 框架，作用应用为 OPPO 健康。
- 上述版本的 OPPO 健康，并允许其使用蓝牙及相关权限。
- 一台支持列表中的设备。

## 安装与使用

1. 从 [Releases](https://github.com/Xposed-Modules-Repo/io.github.brucezhang1993.ohealthdevicebridge/releases) 下载并安装 APK。
2. 在 LSPosed / Xposed 管理器中启用 **OHealth Device Bridge**，作用应用勾选 **OPPO 健康**。
3. 完全退出并重新打开 OPPO 健康。
4. 打开「添加设备 → 体脂秤」，选择对应设备，唤醒体脂秤并按提示完成配对。
5. 站上秤即可测量；也可进入设备的测量页面手动称重。LEN-1001 若广播阻抗为 `0`，这是无有效阻抗的体重记录，不代表代码可以推算出人体电阻。
